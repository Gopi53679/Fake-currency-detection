# 💵 Deep CNN Fake Indian Currency Detection System

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Gopi53679/Fake-currency-detection)

## 🛠️ Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Gopi53679/Fake-currency-detection.git
   cd Fake-currency-detection
   ```

2. **Create a virtual environment & install dependencies**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Run the application**:
   ```bash
   python Backend/app.py
   ```
   Open `http://127.0.0.1:5000` in your browser.
